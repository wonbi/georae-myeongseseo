# 거래명세서 자동 작성

수산물 유통 발주·출고 정산용 거래명세서를 **입력만 하면 미리보기 + PDF 출력**까지 되는 웹앱입니다.

**쓰는 주소 → https://wonbi.github.io/georae-myeongseseo/**

---

## 집·회사 어디서든 이어서 개발하기

이 저장소 하나만 받으면 됩니다. 필요한 건 **git 과 Python** 뿐입니다.

### 처음 한 번 (새 PC에서)

```bash
git clone https://github.com/wonbi/georae-myeongseseo.git
cd georae-myeongseseo
```

### 작업할 때마다

```bash
git pull                 # 1. 다른 곳에서 한 작업 먼저 받기 (반드시 먼저!)
                         # 2. index.html 수정
python build.py          # 3. 빌드 (docs/ 갱신 + 버전 자동 증가)
git add -A
git commit -m "무엇을 바꿨는지"
git push                 # 4. 올리기 -> 30초쯤 뒤 사이트 반영
```

**`git pull` 을 먼저 하는 게 제일 중요합니다.** 안 하면 다른 장소에서 한 작업과 충돌합니다.
자리를 뜰 때는 반드시 `push` 까지 하고 일어나세요.

### 폴더 구조

```
georae-myeongseseo/          <- 저장소 루트 (여기서 작업)
├── index.html               소스. 이 파일을 고칩니다
├── products.js              상품 DB (빌드 때 index.html 안으로 들어감)
├── build.py                 빌드 스크립트
├── parse_sheet.py           구글시트 덤프 -> products.js 변환
├── apps-script.gs           구글시트 연동용 (시트에 붙여넣는 코드)
├── version.json             빌드 번호 (자동 관리, 손대지 마세요)
└── docs/                    빌드 결과. GitHub Pages 가 이 폴더를 서빙합니다
    ├── index.html           단일 파일로 합쳐진 배포본 (직접 고치지 마세요)
    └── vendor/              OCR·PDF 라이브러리 (12MB)
```

`docs/` 안은 `build.py` 가 만들어냅니다. **직접 고치면 다음 빌드에 덮어써집니다.**

### 지금 보는 게 최신인지 확인

화면 좌측 상단 제목 옆의 `v1.6` 같은 버전 칩을 보세요. 빌드할 때마다 올라갑니다.
마우스를 올리면 빌드 시각도 나옵니다.

## 로컬에서 미리 보기

빌드 결과를 브라우저로 확인하려면:

```bash
python -m http.server 8787 --directory docs
```

그다음 http://localhost:8787 을 엽니다.

`docs/index.html` 을 그냥 더블클릭해도 대부분 동작하지만,
**사업자등록증 인식 기능은 서버로 열어야 작동합니다.**

## 주요 기능

**상품 자동 입력**
상품명 칸에 검색어를 입력하면 창고 · 공급가 · 택배비 · 면과세 · 택배사가 한 번에 채워집니다.
공백으로 여러 단어를 넣으면 AND 검색됩니다 (`전복 1kg`). `↑ ↓` 로 이동, `Enter` 로 선택.
자동 입력된 값도 **직접 수정 가능**하며, 수정한 단가는 주황색으로 표시돼 구분됩니다.

**정산 계산**
- 공급가 = 단가 × 수량. **세액 계산은 하지 않습니다.**
- 과세/면세는 상품별로 자동 판정되지만, 금액에는 영향을 주지 않는 **분류 표시**입니다. 명세서의 `세` 칸에 과세/면세로 찍히고, 하단에 과세 품목 합계와 면세 품목 합계가 따로 나옵니다
- 택배비는 품목별 택배비를 자동 합산 (창고가 다르면 건별로 나가므로) — 직접 입력으로 바꿀 수 있음
- 합계금액은 언제나 `단가 × 수량` 의 합 + 택배비 와 정확히 일치합니다

**사업자등록증 드래그로 자동 입력**
공급자·공급받는자 칸 위쪽 점선 영역에 사업자등록증을 끌어다 놓으면 **등록번호 · 상호 · 성명 · 주소**를 읽어 채웁니다. 양쪽 다 같은 항목입니다. PNG · JPG · PDF 를 받습니다.

- **홈택스에서 받은 PDF** 는 파일 안의 글자 정보를 그대로 읽어 정확합니다.
- **사진이나 스캔본** 은 OCR 로 읽습니다. 글자가 틀릴 수 있어 **바로 반영하지 않고** 확인 화면을 먼저 띄웁니다. 값을 고치거나 체크를 해제한 뒤 `선택 항목 채우기` 를 누르세요.
- 인식이 안 된 항목은 붉게 표시되며, 하단 `인식된 원문 보기` 에서 읽어낸 전체 텍스트를 확인할 수 있습니다.
- 사진 인식 엔진은 **처음 한 번만** 내려받습니다(약 12MB). 이후에는 즉시 동작합니다. PDF만 쓰신다면 1.4MB만 받습니다.
- 파일은 브라우저 안에서만 처리되며 **어디로도 전송되지 않습니다.**

**출력**
`PDF 저장 / 인쇄` → 인쇄 대화상자에서 **대상: PDF로 저장** 선택.
A4 세로 기준이며, 여백은 `기본`, 배경 그래픽을 켜면 표 음영까지 그대로 나옵니다.

**저장되는 것** (브라우저에 자동 저장)
- 공급자 정보 — `기본값 저장` 을 한 번 눌러두면 계속 유지
- 거래처 — `거래처 저장` 후 드롭다운에서 재사용
- 작성 중이던 명세서 — 브라우저를 닫아도 복구됨 (`새 명세서` 로 초기화)

## 상품 정보 새로고침

단가가 자주 바뀌므로 두 가지 방법을 넣어뒀습니다.

### 방법 1 — 복사 · 붙여넣기 (설정 불필요)

1. 상단 `↻ 상품 새로고침` 클릭
2. 구글시트에서 **창고명 · 상품명 · 공급가 · 택배사 · 택배비 · 면과세** 열을 포함해 드래그 → `Ctrl+C`
3. 모달 아래 칸에 `Ctrl+V` → `붙여넣은 내용 불러오기`

### 방법 2 — 버튼 한 번으로 자동 (권장, 최초 1회 설정)

1. 구글시트 → `확장 프로그램` → `Apps Script`
2. `apps-script.gs` 내용을 붙여넣고 저장
3. `배포` → `새 배포` → 유형 `웹 앱`
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
4. 나온 웹 앱 URL(`.../exec`)을 복사
5. 웹앱 → `↻ 상품 새로고침` → 연동 주소에 붙여넣기 → `지금 가져오기`

이후로는 `↻ 상품 새로고침` 버튼만 누르면 최신 단가가 반영됩니다.

## 확인이 필요한 부분

- **택배비 분류**: 택배비를 기본적으로 과세 품목으로 분류합니다. 금액에는 영향이 없고 과세/면세 합계 집계에만 반영되므로, 면세로 잡으려면 체크를 해제하세요.
- **택배비 합산**: 품목별 택배비를 모두 더합니다. 한 건으로 묶어 보내신다면 `금액 직접 입력` 을 쓰세요.
- 공급가에 `12,000 > 13,000` 처럼 변동 표기가 있으면 **뒤쪽(변경 후) 값**을 사용합니다.

## 양식 근거

거래명세서 표준 항목은 비즈폼 · 예스폼 · 데모데이 서식을 참조해 구성했습니다.
공급자/공급받는자 정보, 품목(월일·품목·규격·수량·단가·공급가액·세액·비고),
합계금액 한글 표기, 소계/부가세/합계, 전잔금·입금액·미수금, 인수자 확인란을 포함합니다.
